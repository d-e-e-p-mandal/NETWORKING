Goal

Same Secret Key

Do NOT send the secret over the network.

Where Is Private Key Used?

The server’s certificate private key is NOT used to generate the session key directly.

Its job is:

Prove Identity

⸻

During handshake:

Server
   ↓
Signs handshake data
using Private Key

Browser verifies:

Server Public Key

This proves:

This is the real server

So the session key is not transmitted, not stored in the certificate, and not generated by the CA. It is created dynamically during every TLS handshake using Diffie-Hellman/ECDHE mathematics.
